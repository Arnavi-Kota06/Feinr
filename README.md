# Feinr

Feinr is a Generative AI–powered web platform that makes Machine Learning learning accessible, interactive, and personalized. It explains ML concepts using AI-generated text, automatic Python code generation, audio lessons, and visual diagrams.

Built with Python and Flask for the backend and HTML, CSS, and JavaScript for the frontend, Feinr adapts content based on the learner’s preference and understanding level. The platform simplifies complex ML topics and supports different learning styles while reducing dependence on expensive courses.

Tech Stack

Backend: Python, Flask

Frontend: HTML, CSS, JavaScript
